# ATK-MD0700 V2.4 集成与证据

## 型号与验证边界

用户本次确认：底板 **ATK-DNF103P V4.7**（用户输入带一个额外前缀A，本文按ATK标识记录）；屏幕 **ATK-MD0700 V2.4**。MCU工程为STM32F103ZET6。

已获得与屏幕版本严格匹配的厂商原理图，并实际查看整页电路图。已实现可编译的驱动与中文HMI；**未烧录，未实测点亮**。当前尚未取得带V4.7标题栏的底板完整原理图，底板LCD连接按战舰系列厂商资料的NE4/A10映射实现，V4.7逐针连通与插座方向仍是上板前核对项。不能把“屏幕版本资料匹配”写成“整套V4.7硬件实测通过”。

## 一手资料

1. [正点原子官方V2屏幕仓库](https://github.com/openedv/LCD-module_7-inch_ATK-MD0700_800480-V2-)：`1_docs/1_sch/ATK-MD0700_V2.4.pdf`，图纸标题栏V2.4、日期2022/10/21。确认U1=SSD1963、Y1=10MHz、P1=17x2、5V供电、3.3V I/O、U4=MP3302DJ背光电源、PWM来自SSD1963。
2. 同仓库 `1_docs/2_datasheet/SSD1963_DS_V1.1.pdf`：并口命令、读DDB、PLL、RGB565、GRAM、面板时序与PWM寄存器。Rev1.1 §7.4要求PLL启用后等待100ms，本项目用非阻塞阶段等待。
3. 同仓库 `AT070TN92.pdf`：原生800x480，典型像素时钟33.3MHz、HT1056、VT525、H blank46、V blank23、脉冲宽1可用。README将480*800按竖屏列出，本文使用面板手册确认横屏800x480。
4. [正点原子官方F103参考工程](https://github.com/openedv/M144Z-M3-Mini-Board-STM32F103/tree/master/example/10_tftlcd_mcu/BSP/LCD)：SSD1963初始化与读取0xA1得到0x5761可交叉核查。**此工程的底板是Mini，不能拿其GPIO当战舰引脚**。本项目按数据手册重新实现，不复制整套受版权保护的驱动/字库。
5. [战舰V4官方资料入口](https://www.openedv.com/docs/boards/stm32/zdyz_stm32f103_warshipV4.html)：A盘百度网盘，提取码dka8。V4.7底板原理图、硬件手册应从这里补齐，不能用V3跳线编号代替。
6. 战舰系列厂商源码中的地址说明：NE4→LCD_CS，A10→LCD_RS，CPU数据地址0x6C000800；本次也核对了保留厂商头注释的战舰V4工程镜像。镜像存在改动，**只作为定位线索，不作为V4.7逐针原理图证据**。原理图证据等级与实现配置必须区分。

屏幕原理图下方同时画出电阻/电容触摸的装配选项。官方README列FT5206，但资料目录同时含GT911、FT5x26等器件手册；仅凭PCB版本无法证明用户这一块实际焊装的触摸芯片。首版**不启用触摸GPIO**，由KEY0操作，避免误认XPT2046为本屏实际触摸芯片。

## 总线与资源审计

| 信号 | 当前固件配置 | 说明 |
|---|---|---|
|D0,D1|PD14,PD15|FSMC数据|
|D2,D3|PD0,PD1|FSMC数据|
|D4..D12|PE7..PE15|FSMC数据；不覆盖PE4|
|D13..D15|PD8..PD10|FSMC数据|
|WR/RD|PD5/PD4|FSMC_NWE/NOE|
|CS/RS|PG12/PG0|FSMC_NE4/A10；V4.7插座连通待核对|
|RESET|模块P1-5|接底板复位网络；固件不另驱动未知RST GPIO|
|背光|SSD1963 PWM→MP3302 EN|使用0xBE指令；V2.4模块P1-23是TE，不把PB0配置为背光输出|
|KEY0|PE4低有效|保留原工程，20ms消抖/1s长按|
|DS0|PB5低有效|保留原工程|
|USART1|PA9 TX / PA10 RX|与上述LCD无冲突；板载桥接跳线待实物核对|
|SWD|PA13/PA14|保留，不占用|
|TIM3|仅内部100Hz中断|不映射CH引脚，不配置PWM|
|触摸|未配置|PB1/PB2/PF9/PF10/PF11均不由本项目驱动|

FSMC只设置Bank1的块4，其他片选保持原样。异步16bit SRAM模式，读地址6HCLK+数据25HCLK，写地址4HCLK+数据9HCLK；HCLK=72MHz。时序取保守值，实物稳定性/速度尚待观察。

`lcd_panel.c`分阶段：上电等待→读DDB→PLL100MHz/等待100ms→软件复位→面板寄存器→显示使能。像素时钟设置FPR=0x0553F7，100MHz*(FPR+1)/2^20≈33.3MHz；HT=1056、VT=525；RGB565，0°横屏，800x480。未实现触摸与运行时旋转；自检四角标记用于验证默认方向，用户反馈倒置再按真实面板修订。

## 中文与刷新

中文采用24x24单色点阵（标题32px），仅收录界面使用的汉字/标点，`tools/generate_font.py`可从本机微软雅黑重新生成。生成后的C表直接进入Flash，MCU不需字体文件、SD卡或外扩RAM。未打包完整字体。ASCII为本项目紧凑5x7字模按比例显示，小写统一显示为大写。

无整帧RAM缓冲，少量行缓存。启动/色块每次处理8行；主界面分字段更新，刷新周期200ms，每轮只做一个字段。C原生测试使用的800x480缓冲**仅位于tests/lcd_mock.c，不进入MCU构建**。

## 用户上板顺序

1. 断电核对底板V4.7 LCD座的1脚、模块1脚、5V/GND/RESET和上述总线；不凭“靠左/靠右”文字盲插。
2. 使用开发板套件中已配套、极性和规格匹配的供电方式；7寸背光电流较大，不能将USB有电认定为供电充足；不向3.3V引脚接5V。
3. 用户自行烧录Debug ELF。先按住KEY0，再按下/释放RESET，保持KEY0约1秒后松开。开机采样到KEY0按下即进入自检。长按事件在自检中被消耗，不自动退出；再次短按KEY0退出。
4. 应看到红/绿/蓝/白/黑各约1秒、中文文字、四角不同色标。通过后复位进入主界面。
5. 若完全黑屏，调试查看`lcd_diag.id/stage/error`：0x5761才会进入初始化；0/FFFF优先查电源/插接/CS/RS/RD/总线，而不是强制跳过ID检查。初始背光关闭，未读到ID时不会把背光亮当作成功。
6. ID正确但不显示：先看stage是否结束，再核对屏上晶振、背光供电与PWM、B0/B4/B6/F0；能显示色块而文字缺字时查`lcd_diag.missing_glyphs`；方向错误拍下四角色标后修改0x36/面板方向配置。
7. 能显示主界面后再接PC，按KEY0进入运行态，观察串口计数、目标图形；拔线应离线并归零。

阻塞只剩硬件验收：V4.7底板插座/桥接跳线核对，LCD实物点亮与串口回包。软件模拟不能替代这些验收。
